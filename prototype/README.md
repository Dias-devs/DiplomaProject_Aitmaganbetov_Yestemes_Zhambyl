# UX Prototype

DLM-7

This folder contains the UX prototype of our digital literacy mobile application for children aged 6-10.

**Interactive prototype:** https://coil-new-91554122.figma.site

**Figma Make project:** https://www.figma.com/make/QQshgZrALtU8CD4N4fAHTj/%D0%A6%D0%B8%D1%84%D1%80%D0%BE%D0%9C%D0%B8%D1%80--%D0%A3%D1%87%D0%B8%D0%BC%D1%81%D1%8F-%D0%B1%D0%B5%D0%B7%D0%BE%D0%BF%D0%B0%D1%81%D0%BD%D0%BE?t=AGLYrm5lc7g72wGJ-1

The prototype was prepared in Figma Make and reviewed by the project team.

It demonstrates three learning topics:

Digital devices

Personal information

Internet safety

The main user flow includes lesson selection, interactive questions, optional hints, answer feedback, lesson completion, and progress tracking.

The prototype uses sample learning content and simulated application logic. It is not connected to the planned Flutter application, Node.js/Express backend, or production database.

Screenshots of the main screens are included in this folder.
